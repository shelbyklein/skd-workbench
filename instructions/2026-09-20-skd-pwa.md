## Implementation

Keep the existing icon; derive deterministic PNG sizes from its SVG. Add manifest and service worker at the origin root. Precache only an explicit allowlist of public shell assets. Version the worker cache; use cache-first for a coherent shell. Do not skipWaiting on install: wait for a user-approved update, then reload that tab on controllerchange; other tabs retain their drafts. No API/cache fallback, background sync, notifications, telemetry or queues. Failed API calls show server unavailable and retain the editor. Offline startup shows launch/reconnect instructions. Local server remains required for all project/Git/workflow operations. Check server availability directly rather than treating navigator.onLine as proof of localhost health.

Installation action is optional enhancement: beforeinstallprompt when available, browser fallback instructions otherwise. The in-app browser may not offer installation; give a canonical external-browser URL. No browser profile automation or install claim without evidence. Current desktop setup remains loopback-only; mobile devices cannot reach this Mac's localhost.

Verify against temporary stores/ports. Worker lifecycle test uses a temporary asset copy to publish a changed worker; never alters live assets for testing. Do not cache user folders, prompts, Git state or run data. Live restart uses existing transient launchctl job only; no login service changes. Rollback must account for installed workers: ship an unregister/cleanup worker if retiring the PWA instead of merely deleting sw.js.

Sources: https://web.dev/learn/pwa/installation-prompt and https://web.dev/learn/pwa/update.
