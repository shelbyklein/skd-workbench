## Ownership and interfaces

Coordinator owns server.js, lib/terminals.js, lib/workspace-registration.js, public/git-status-ui.js, app wiring, cache/docs/package and final integration. Service worker owns lib/workspace-tasks.js and tests/workspace-tasks.test.js only. UI worker owns public/workspace-tasks-ui.js and tests/workspace-tasks-browser.mjs only.

Export WorkspaceTasks(directory,{notes,gitStatus,executor,terminals,project,projects,originContext}). project(id) returns current project, projects() returns connected projects, originContext(registration) returns original {task,acceptance} or null using verified recorded source IDs. Helper uses existing registration UUIDs; tasks persist acceptance/original task once, linked by registrationID. No copying TT/GitHub checklist.

preview(project,input): input {snapshotID,projectVersion,worktreeID}. Read-only Git inspection plus bounded dirty fingerprint (tracked diff and untracked content hash) and filesystem attachment identity. Refuse stale/partial/unavailable/locked/detached/pending operation, primary/main/target worktrees, another connected project's source checkout, benchmark project/registration. Existing registration mismatch is blocked, never silently adopted. Return {id,projectVersion,path,branch,dirty,worktreeID,registrationID,taskID,purpose,workRef,acceptance,originalTask,expiresAt}. Preview only generates in-memory expiring state, no provider/process/storage mutation. TaskID present means continuation available. For registered work without task association, use original task/acceptance in adoption and preserve immutable origin. Existing purpose/workRef are not changed by association.

adopt(project,input): {previewID,requestKey,purpose,workRef,acceptance,confirmOwnership:true}. Explicit claim of no external writer and acceptance of current dirty changes. Revalidate preview/fingerprint/fs identity and current project under shared executor ownership. Persist durable idempotent adoption intent/task BEFORE notes.prepare/attach. Never create/move/rename/delete Git worktrees. If existing verified registration reuse UUID/ownerKey, never replace it. New registration ownerKey='task:'+taskID, origin={kind:'adoption',id:taskID}, local workRef default. notes.prepare then attach verify expected preview identity before declaring attached. Persist immutable original task/acceptance from originContext when available; user purpose/acceptance only for external missing originals. Returns task record. Failure retains records/folder visibly and blocks launch. Duplicate same request returns same record, conflicting request rejects. Restart never applies/launches pending intent; explicit fresh adoption may recover only unchanged same intent.

continue(project,input): {previewID,requestKey,agent,model,effort,task,confirmOwnership:true}. task is next instruction (required), not replacement acceptance. Existing saved task must be attached, same project, verified registration and exact preview. Persist idempotent continuation intent before launch; recheck preview inside terminal's ownership gate via provided shouldLaunch callback. Call terminals.start with mode worktree plus internal workspace object; no git worktree add. internal workspace={workingDirectory:registered destination,worktreePath,branch,sourceContext:CURRENT capture with actual commit,workspaceRegistrationID,workspaceOwnerKey:notes ownerKey,taskID}; initialPrompt includes immutable original task/acceptance, current purpose and next instruction. Returns {sessionID,...}. Repeat/lost response never spawns twice; pending/failed/interrupted requests require fresh explicit attempt, never automatic retry. Existing global execution lock stays intact.

list(project) returns project-scoped tasks and incomplete adoption/continuation operations; source links never leak other projects. APIs resolve all paths server-side. APIs: POST /api/projects/:id/workspace-tasks/preview|adopt|continue and GET /api/projects/:id/workspace-tasks. No arbitrary input paths or caller-owned workspace object.
